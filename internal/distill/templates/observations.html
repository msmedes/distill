What are project promotions?
Project-scoped observations write portable artifacts in the project: AGENTS.md or .agents/skills.
When should something become a skill?
Use a skill for situational guidance: a workflow, domain, repo pattern, or task type that should load only when it is relevant.
Does distill write these automatically?
No. It can propose a destination, but nothing is written until you accept a proposal or use a promotion action.
