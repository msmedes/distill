distill. help

observations

distill turns repeated signals from your Claude Code and Codex sessions into observations. You curate those observations, then choose whether any of them should become durable agent guidance.

promotion destinations

What are instructions?
Instructions are AGENTS.md-style files. User-scoped observations write your configured user instructions; project-scoped observations write <project>/AGENTS.md.
What is a skill?
A skill is a generated SKILL.md file for situational guidance: a workflow, domain, repo pattern, or task type that should load only when it is relevant.
What is skills dir?
The user skills directory is where distill writes user-scoped generated skill folders. Project-scoped skills write <project>/.agents/skills/<name>/SKILL.md.

choosing a destination

  • Use user instructions for terse rules that should shape every agent session.
  • Use project instructions for conventions learned from one repository.
  • Use a skill for guidance that depends on a task, repo, tool, or workflow.
  • Leave the observation active if the signal is plausible but not yet durable enough.
  • Ignore an observation when it is wrong, stale, too noisy, or not worth preserving.

proposals

Proposals are recommendations, not writes. The model can suggest artifact and scope, such as a project skill or user instructions, but distill does not modify those files until you accept a proposal or use a promotion action.

Accepting a proposal is the commit point. Before that, the observation is just local curation data.

what gets written

Instruction promotion
distill asks Opus to integrate the observation into the scoped instruction file, then shows a diff for you to review before committing.
Skill promotion
distill asks the model to turn the observation, evidence, and notes into a compact skill file, then writes it under the user or project portable skills directory.
Portable artifacts
distill writes predictable AGENTS.md and .agents/skills artifacts. If an agent runtime expects another path, symlink, copy, or configure that runtime separately.
Source sessions
distill reads Claude Code and Codex transcripts. It does not modify source session files.
